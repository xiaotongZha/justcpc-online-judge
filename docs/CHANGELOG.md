# 更新记录

## 1.0.1 · 2026-10-20

- Linux 安装、更新、卸载改为每个项目独立的 Shell 脚本，删除通用 Go 安装工具；README 提供 mkdir/curl/执行安装的完整命令。
- 安装下载最新正式版，发行包附带更新和卸载脚本；更新确认后原地替换，保留配置与数据，卸载可选择是否清理数据。
- 开发资料、配置模板和构建产物分别归入 docs、config、build；项目名称保持完整。

## 1.0.0 · 2026-10-19

- 重整工作台与比赛创建页面，题库和比赛列表采用紧凑单行布局并支持分页。
- 正式题面 PDF 支持上传预览，CSV / XLSX 名单提供格式模板和严格校验；考试包 / 提交包导入增加预览与交接引导。
- 成绩单优先展示有提交的考生，明确导入后需手动开始评测；题目保持独立详情页，刷新可恢复当前页面。
- 题目编辑合并资源限制，浮点误差配置移至测试数据区域；支持下载已有测试数据 ZIP。
- 逐测试点移除诊断信息列；仅管理员及题目出题人可下载 N.in / N.out，服务端独立鉴权，同一账号同一文件限制 5 秒重复下载。
